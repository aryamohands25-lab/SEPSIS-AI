Important interpretation
This archive contains a QUICK-RUN / smoke-test training configuration to make
execution feasible in a constrained environment. The training split was
subsampled to 2% of train patients for model fitting; validation and test
metrics were calculated on their full patient-level splits. These results are
for pipeline verification, not final clinical claims or publication. Run
`python run_all.py` without SEPSIS_FAST=1 for the full training experiment.

Runtime compatibility
The execution environment did not have pyarrow/fastparquet and had no network
access to install them. Data files with `.parquet` suffix in this archive were
therefore stored as pickle and are read through `src.config.read_table()`.
Install requirements (including pyarrow) for normal Parquet output on your
computer. The helper also reads the prepared pickle fallback files.
